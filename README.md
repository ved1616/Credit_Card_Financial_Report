# Credit_Card_Financial_Report
PowerBI Dashboard

### Project Objectives

1. **Analyze credit card transaction data** to understand revenue and transaction trends.
2. **Track key financial KPIs** such as total revenue, transaction count, income, and interest earned.
3. **Analyze revenue across different quarters and weeks** to identify trends and changes over time.
4. **Compare customer segments** based on gender, card category, education level, marital status, and occupation.
5. **Analyze transaction behavior** based on expense type and transaction method such as Swipe, Chip, and Online.
6. **Identify high-performing card categories and customer segments** based on revenue and transaction volume.
7. **Build an interactive Power BI dashboard** using slicers, charts, cards, and tables for easy analysis.
8. **Provide meaningful business insights** that can help understand customer spending and financial performance.

## Project Steps

1. **Collect the Dataset**

   * Obtained the credit card customer and transaction dataset.

2. **Data Cleaning**

   * Removed duplicate records.
   * Handled missing and incorrect values.
   * Standardized column names and data formats.

3. **Data Preparation**

   * Created/modified columns required for analysis.
   * Prepared date, quarter, week, gender, card category, and transaction-related fields.

4. **Data Modeling**

   * Imported the datasets into Power BI.
   * Created relationships between customer and credit-card detail tables.
   * Checked relationship cardinality and filter direction.

5. **DAX Calculations**

   * Created measures for:

     * Total Revenue
     * Total Transaction Count
     * Total Income
     * Total Interest Earned
     * Revenue by Quarter
     * Revenue by Customer Segment

6. **Dashboard Development**

   * Created KPI cards for major financial metrics.
   * Created charts for quarterly and weekly transaction trends.
   * Created visualizations for card category, expense type, gender, education, marital status, and customer job.

7. **Interactive Analysis**

   * Added slicers for **week, gender, quarter, card category, transaction type, and other relevant fields**.
   * Enabled users to filter and analyze the dashboard dynamically.

8. **Insight Generation**

   * Compared revenue and transaction volumes across different customer segments.
   * Identified high-revenue card categories and expense types.
   * Analyzed quarterly and weekly performance trends.

9. **Final Dashboard**

   * Designed an interactive **Credit Card Financial Report** dashboard to present the analysis clearly and support business decision-making.
